This site is built by a small C program and served from my homelab: NixOS machines in a k3s cluster, managed with Argo CD. The same cluster runs nightly CI for the projects I contribute to, on a GPU node, a Mac and a Raspberry Pi 5.

It also benchmarks Keras every night on each backend, including MLX on an M4 Mac. The history is under [:bench](/bench/), press 4.
